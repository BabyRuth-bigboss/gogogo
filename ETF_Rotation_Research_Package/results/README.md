# 结果目录说明

- `summaries/`：每个历史回测目录的最新 Markdown 总结，文件名前缀保留原输出目录名。
- `v2/`：V2 的参数表、压力测试、最佳权益曲线、成交与信号记录。
- `v21/`：V2.1 的全量参数表、压力测试、推荐策略权益曲线、成交与信号记录。
- `selected_metrics/`：其它策略的机器可读指标快照；个别文件名在源目录中相同，主要用于快速浏览，完整口径以 `summaries/` 为准。
- 根目录：V2 最新信号快照、ETF 池审计结果和动量模型说明。

所有文件都是截至 2026-07-11 的历史研究快照；重新运行脚本会生成新的 `a_stock_daily_workflow/` 输出。
