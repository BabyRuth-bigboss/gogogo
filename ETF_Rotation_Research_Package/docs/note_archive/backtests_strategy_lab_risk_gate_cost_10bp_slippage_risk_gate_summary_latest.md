# ETF组合回撤风险闸门回测：佣金万0.5 + 滑点0.10%

- 规则：信号日收盘后，如果组合权益相对本轮峰值回撤超过阈值，则下一交易日开盘执行风险动作。
- 本版主测：12%不清仓，改为把组合目标仓位降到50%。
- 对照：保留12%清仓；附带10%、15%降半仓用于敏感性观察。
- 成交口径：信号日收盘后计算，下一交易日开盘成交；单边成本=佣金0.005% + 滑点0.10% = 0.105%。

## 策略说明

- 低波RS月频Top3：每月第一个交易日调仓；评分=3个月收益45% + 6个月收益45% - 60日波动10%；只买收盘价高于MA120且6个月收益为正的ETF；取前3名等权。它是进攻型强趋势策略。
- RS612月频Top2：每月第一个交易日调仓；评分=6个月收益50% + 12个月收益50%；只买收盘价高于MA200且12个月收益为正的ETF；取前2名等权。它更慢，更依赖中长期趋势延续。
- 核心卫星50/50：每月第一个交易日调仓；核心资产从红利、纳指、标普500、现金流里选1只占50%，其余50%给RS强的行业/主题ETF。它是防守对照组。
- RS36月频Top3+市场过滤：每月第一个交易日调仓；评分=3个月收益50% + 6个月收益50%；沪深300、创业板、科创50里至少2个满足高于MA120且6个月收益为正，才允许开仓；取前3名等权。它是带市场环境过滤的趋势策略。

## 风险闸门说明

- 无闸门：策略正常月频调仓。
- 12%清仓：组合权益相对本轮峰值回撤超过12%，下一交易日开盘全部卖出，之后等下次调仓信号。
- 10%/12%/15%降半仓：组合权益相对本轮峰值回撤超过阈值，下一交易日开盘把当时目标仓位降到50%，之后等下次正常调仓恢复。
