# ETF 5年真实动态池回测

- 生成日期：2026-07-10
- 回测口径：真实ETF动态池，ETF必须已有252个交易日历史才允许参与打分。
- 标的池：当前ETF池 41 只；不是固定幸存者全程可买。
- 数据源：腾讯日线 raw day，最多 1800 根；对ETF份额拆分/合并做连续化调整。
- 成本：佣金万0.5 + 滑点0.10%，单边合计 0.105%。
- 信号：调仓日前一交易日收盘后计算；成交：下一交易日开盘成交。
- 停牌/缺当天K线处理：持仓估值用上一可得收盘价兜底；交易仍要求成交日有开盘价。
- 注意：拆分调整只修正大比例份额拆分/合并，不等同于完整分红复权；红利类收益仍可能被低估。
