# Obsidian 简明使用教程

欢迎使用 Obsidian！这是一个基于本地 Markdown 文件的强大个人知识库（Vault）。为了配合您刚刚整理好的扁平化笔记库，本教程将带您快速掌握 Obsidian 的核心操作与高效管理技巧。

---

## 1. 核心概念：双向链接（Backlinks）

Obsidian 最强大的功能是**双向链接**，它能帮助你把碎片化的笔记编织成网状知识库。

* **创建链接**：输入 `[[` 即可触发自动补全，选择你想链接的笔记名称。
  * *示例*：在阅读某篇设计方案时，可以写入 `[[docs_plans_2026-07-11-a-share-factor-lab-design]]`。
* **自定义显示别名**：使用 `|` 管道符定义链接显示的文字。
  * *示例*：`[[docs_plans_2026-07-11-a-share-factor-lab-design|因子研究设计方案]]`。
* **查看反向链接**：在任意笔记的右侧栏中，可以查看“有哪些其他笔记链接了当前笔记”，从而轻松追踪思路来源。

---

## 2. 标签系统（Tags）与层级搜索

因为您的笔记库目前采用了**扁平化结构**（无子文件夹），使用 **标签（Tags）** 是最完美的整理与分类手段。

### 2.1 标签格式
目前您的笔记中都已自动加上了 YAML 前置元数据，格式如下：
```yaml
---
tags:
  - quant/backtest
  - etf
---
```
* 您也可以直接在文章正文中书写标签，如 `#etf` 或 `#quant/backtest`。

### 2.2 层级标签（Nested Tags）
* 标签支持使用 `/` 进行分层，例如 `#quant/backtest` 和 `#quant/factor`。
* 在标签面板中，你可以直接折叠 `#quant`，也可以单独筛选子类别。

### 2.3 标签搜索技巧
按快捷键 `Cmd + Shift + F` (Mac) 打开全局搜索：
* 搜索包含特定标签的笔记：`tag:#quant/backtest`
* 搜索未打标签的笔记：`-tag:#`
* 搜索同时含有多个标签的笔记：`tag:#etf tag:#quant/backtest`

## 3. 常用快捷键（提效神器）

熟练使用快捷键可以大幅提升记录和查阅体验：

| 快捷键 (Mac) | 功能 | 说明 |
| :--- | :--- | :--- |
| `Cmd + P` | **打开命令面板** | 可以执行 Obsidian 的所有命令（如切换日/夜间模式、导出 PDF 等） |
| `Cmd + O` | **快速切换/搜索文件** | 输入文件名关键字即可极速跳转笔记 |
| `Cmd + Shift + F` | **全局搜索** | 搜索整个知识库中的文本内容 |
| `Cmd + E` | **切换编辑/阅读模式** | 在 Markdown 源码编辑与渲染效果之间切换 |
| `Cmd + Option + ←/→` | **历史导航（返回/前进）** | 类似浏览器的前进和后退，非常适合跨笔记阅读 |

---

## 4. 推荐探索的高级功能

1. **关系图谱（Graph View）**：
   * 点击左侧侧边栏的“齿轮/网状”图标，或者通过 `Cmd + P` 搜 `Graph view` 打开。
   * 它会以可视化球网结构呈现你所有笔记的链接关系。可以通过颜色对不同的标签进行染色（如把 `#quant` 染成蓝色），知识分布一目了然。
2. **核心插件启用**：
   * 点击左下角齿轮 **设置** -> **核心插件 (Core plugins)**。
   * 建议开启：**关系图谱 (Graph view)**、**反向链接 (Backlinks)**、**大纲 (Outline)**（适合查看长回测报告的目录结构）。
