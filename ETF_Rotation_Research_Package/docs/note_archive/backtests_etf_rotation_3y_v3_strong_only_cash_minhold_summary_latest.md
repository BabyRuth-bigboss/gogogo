# ETF动量轮动3年回测 V3

区间：2023-07-11 至 2026-07-09  |  标的池：41只行业/主题ETF

## 规则
- 每日收盘后用当日及之前数据评分；普通轮动只在每周首个交易日开盘调仓。
- 持仓若触发20日最大回撤超过12%或跌破MA20且10日动量转负，次日强制清仓，不等周频。
- 只允许 strong 市场开新仓；neutral 只持有不新开；weak 次日强制降到现金。
- 持仓至少5个交易日不做普通轮动卖出，除非触发清仓/弱市现金规则。
- ETF完整卖出后冷却10个交易日，冷却期内不重新买回同一ETF。
- 五维：10/20日动量、历史溢价中性分、20日回撤、相对强度、动量差距。
- 同主题ETF只取最强；单只最高60%，最多3只；20日动量>30%仓位上限45%。
- 成本：ETF无印花税，单边佣金0.03% + 滑点0.05%；小于组合净值2%的微调不交易。
- 注意：历史ETF溢价数据未稳定还原，本次不做历史溢价否决，实盘日报仍会使用实时溢价。
