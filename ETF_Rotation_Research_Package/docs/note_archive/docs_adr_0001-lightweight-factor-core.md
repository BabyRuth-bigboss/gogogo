# ADR-0001：使用轻量因子研究内核并隔离实盘执行

## 状态
Accepted

## 背景
当前目标是快速验证 ETF 和个股因子的横截面表现，同时未来可能接入 A 股券商终端。研究阶段最重要的是时间对齐、数据质量和可解释性，而非一次性引入完整交易平台。

## 决策
使用 pandas 构建可审计的模块化单体，以规范化长表作为模块边界。Qlib 保留为机器学习与 Alpha158/360 扩展，VeighNa/QMT 保留为执行适配器。任何实盘执行默认关闭且不进入研究进程。

## 后果

### 正面
- 因子值、未来收益、持仓和费用可以逐行检查。
- ETF MVP 依赖少，能快速离线测试。
- 数据源与券商可以替换而无需改写因子。

### 负面
- 首版撮合不覆盖全部 A 股微观规则。
- 大规模全市场训练的性能不如 Qlib 二进制数据层。
- 免费数据不保证 Point-in-Time 完整性。

## 备选方案
- Qlib：适合后续机器学习研究，但首轮配置和数据准备更重。
- RQAlpha：A 股撮合规则成熟，但因子诊断不是其最轻路径，且需关注许可和数据服务。
- Backtrader：通用性好，但 A 股规则仍需自行扩展。
