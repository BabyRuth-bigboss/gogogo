# A 股因子研究与量化交易系统设计

## 目标与边界

第一阶段交付一个可在 ETF 或 A 股日线数据上运行的因子研究 MVP：下载并缓存数据、计算因子、评估 IC 与分组收益、按横截面排名构建组合、计入双边费用与滑点、输出净值和绩效。信号在 T 日收盘后形成，最早在 T+1 收盘成交，避免使用未来信息。真实券商下单不在第一阶段启用，只定义执行接口边界。

非功能要求是可审计、可复现、离线可测试和默认安全。原始数据与研究结果分目录保存；配置和结果包含日期、标的池、参数及成本。对于个股，免费数据不能彻底消除幸存者偏差、历史成分股偏差和财务数据披露时点偏差，因此 MVP 更适合 ETF 与固定的研究样本；全市场个股研究应升级为 Point-in-Time 数据。

## 架构与数据流

```text
AKShare/本地CSV -> 规范化长表 -> 因子计算 -> IC/分组分析
                         |             |
                         +------> 组合权重 -> T+1成交/费用 -> 绩效报告
                                                     |
                                              PaperBroker
                                                     |
                                      [人工解锁后] QMT/VeighNa
```

组件采用单机 Python 模块化单体：`data` 负责字段和缓存，`factors` 只消费规范化数据，`analysis` 评估预测能力，`backtest` 处理换仓和成本，`cli` 编排任务。研究层不直接导入券商 SDK，从结构上阻止回测代码误下实盘单。

## 失败模式与验证

数据缺列、重复日期、非正价格会立即报错；单个标的下载失败不会产生伪造数据。交易成本按换手率扣除，股票卖出额外计印花税，ETF 默认不计印花税。首版不模拟一字涨跌停、停牌后排队成交、最小 100 股和最低 5 元佣金，这些在接入个股实盘前必须补齐。

测试使用合成数据验证：因子不会读取未来值、权重滞后一日生效、成本降低收益、绩效指标稳定。实盘推进门槛为至少 5 年数据、多个市场状态、100 笔以上交易、样本外/滚动验证、成本翻倍压力测试以及至少 4 周模拟盘。
