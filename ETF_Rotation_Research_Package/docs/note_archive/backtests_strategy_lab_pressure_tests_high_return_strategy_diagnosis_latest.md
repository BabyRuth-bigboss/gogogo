# 高收益ETF轮动策略压力诊断

回测口径：信号日收盘后计算，下一交易日开盘成交；基准成本为佣金0.03% + 滑点0.05%，压力成本为成本翻倍。ETF池压力项只恢复此前因2020-2025长期亏损删除的医疗器械、生物科技两只ETF。

## 判断

- 低波RS月频Top3：成本翻倍后只从+220.65%降到+213.09%，ETF池还原后没有变化；不同起点下仍然强，说明短期不是成本或单个标的造成的虚高。问题是它接近满仓，2023年回撤和年度亏损都存在，属于进攻策略，不是防守策略。
- RS612月频Top2：成本和ETF池压力也没有打散，但市场过滤后收益从+191.95%降到+58.93%，说明它依赖长期趋势连续持有；一旦加大择时防守，会牺牲很多收益。
- 市场过滤：对高收益策略的回撤改善有限，收益牺牲很大。低波RS加2/3过滤后回撤从-23.59%降到-17.22%，但总收益降到+96.55%；RS612加2/3过滤后回撤从-21.09%降到-19.18%，总收益降到+58.93%。
- 当前结论：低波RS月频Top3更值得进入下一轮候选；RS612月频Top2可作为慢趋势进攻备选；核心卫星和RS36市场过滤仍然是防守对照组。

## 下一轮建议

- 给低波RS增加风险闸门，但不要直接套强市场过滤；优先测试“组合回撤超过12%降半仓/清仓”“连续两个月亏损后下月半仓”“指数MA120下只买1只或空仓”。
- 对RS612测试更低频的季度调仓或月频但持仓冻结两个月，避免长期趋势策略被月度噪音打断。
- 做更长周期或扩展到2018以后数据；当前三年样本里，2025-2026贡献过大，不能直接当成稳定年化。
