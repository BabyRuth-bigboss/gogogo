# ETF双袖轮动V2.1优化设计

## 目标

在保留V2高收益特征的前提下，降低Top2集中风险、快速下跌识别滞后和防御袖全球共振风险。胜出标准为收益优先，同时争取将全期及压力测试最大回撤控制在20%以内。

## 可验证假设

1. Top3或Top4可以降低单标的风险，且不会显著破坏动量收益。
2. 多个A股指数短期同步急跌时，立即进入防御袖可以减少MA120状态机的确认滞后。
3. 黄金ETF加入防御池，可以在A股与美股共振下跌时提供第三种选择。
4. 训练期胜出参数在2024-2026独立测试期仍有效，才比全样本最优更可信。

## 参数空间

- 进攻持仓结构：Top2各50%；Top3测试45/45/10、45/40/15、42/42/16、45/35/20、40/40/20和等权；Top4等权。
- 紧急闸门：关闭；2/4 A股指数5日跌幅低于-5%、-7%、-9%。
- 紧急防御最短持续期：5个交易日。
- 防御池：纳指+标普；纳指+标普+黄金。
- 防御趋势：MA120且6个月收益为正；MA200且12个月收益为正。
- 防御持仓数：Top1、Top2。
- V2主状态机固定：MA120、斜率20日、连续2日确认、冷却5日、六指数。

## 数据与执行

- 使用腾讯二级市场ETF日线，信号日收盘计算，下一交易日开盘成交。
- 初始资金100万元。
- 佣金万0.5，滑点0.10%，单边合计0.105%。
- ETF上市满252个交易日后才能进入候选池。
- 黄金ETF代码518880，仅作为防御候选。

## 验证

- 全期：最近5年。
- 训练期：2021-07至2023-12。
- 独立测试期：2024-01至2026-07。
- 压力测试：成本1倍和2倍，不同起始日期。
- 输出完整净值、交易、信号和指标文件。

## QDII溢价处理

腾讯日线是ETF二级市场成交价，因此历史溢价上涨和收敛已经体现在价格收益中。但仓库没有完整历史NAV/IOPV，不能准确回测“溢价超过2%禁止买入”。V2.1不伪造历史溢价，后续应接入带时间戳的NAV/IOPV后单独验证。
