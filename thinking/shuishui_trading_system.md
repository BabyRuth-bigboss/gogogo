# 水水股票交易体系

## 系统定位

适用于 A 股主线题材、强势股和 ETF/个股的**右侧交易**。目标不是预测所有上涨，而是在市场、主线和结构同时允许时，以有限亏损换取 2R 以上的赔率。

```text
主线 -> 核心票 -> 标准图 -> 盈亏比 -> 仓位 -> 止损执行
```

## 五道开仓闸门

| 闸门 | 必须回答的问题 | 不通过时 |
|---|---|---|
| 市场 | 指数趋势、流动性和情绪是否支持做多？ | 不开新仓 |
| 主线 | 行业是否属于资金正在强化或扩散的方向？ | 降为观察 |
| 地位 | 是否为龙头、次龙头、核心成分/ETF 重仓或高辨识度标的？ | 降级 |
| 图形 | 是否属于标准 A/B/C/D 图形，而非主观“看着强”？ | 等待 |
| 交易 | 入场、止损、目标、RR、流动性与 T+1 风险是否可量化？ | 不交易 |

## 标准图形

| 模型 | 条件 | 触发 | 常用失效条件 |
|---|---|---|---|
| A 突破 | 横向压力 + 下降压力线 + 缩量整理，最好是主线强股 | 收盘越过压力、量能大于 20 日均量 1.5 倍；交点附近是优先观察区 | 3 日内跌回平台、突破长上影未修复、板块跌破 MA20 |
| B 商品映射 | 期货/现货先行，产业链股票或 ETF 补涨 | 标的突破平台/MA20/MA60，且商品、板块、标的至少两项确认 | 商品跌破 MA20、无扩散、3--5 日不补涨 |
| C 箱体突破 | 大跌后长箱体，通常至少 60 个交易日 | 放量突破箱体上沿，优先等回踩上沿不破 | 回落箱体、回踩放量杀跌、板块不配合 |
| D 趋势回踩 | 上升趋势的 3/5 浪延续 | 回踩守住前高、MA20 或平台后重新放量 | 跌破关键低点、反弹不能创新高、高位放量阴线 |
| R 风险图形 | 失败突破、跌破趋势线、右肩、低高点/低低点、放量滞涨 | 不买 | 删除或等待结构修复 |

## 评分与股票池

```text
总分 = 市场10 + 板块20 + 个股地位15 + 图形25 + 量能10 + 盈亏比10 + 执行10 - 风险扣分(最多30)
```

| 分数 | 池子 | 执行 |
|---:|---|---|
| 90--100 | A 池 | 计划完整后可交易 |
| 80--89 | A/B 池 | 等精确触发或小仓 |
| 70--79 | B/C 池 | 只观察 |
| <70 或 R | D/删除 | 不交易 |

## 风险、仓位与止损

设入场价 `E`、止损价 `S`、目标价 `T`：

```text
单笔风险 R = E - S
盈亏比 RR = (T - E) / (E - S)
允许亏损 = 账户资金 x 单笔风险预算
股数 = 允许亏损 / (E - S + 预估滑点)
```

- 最低 `RR >= 2`；`RR 3--5` 更优，前提是目标合理。
- 模拟盘单笔风险可为 1--2%；小资金实盘 0.3--0.8%；稳定实盘通常 0.5--1.0%。
- 分数 80--84 的初始仓位约 3--5%，90+ 且 RR>3 可 8--10%，但仍受单笔风险上限约束。
- A 股须用极端风险覆盖普通止损：主板、创业板/科创板的跌停与 T+1 使“理论止损”无法保证成交。
- 结构失效即执行止损；不摊平，不把失败的右侧交易改名为价值投资。

## 日常流程

1. 先判市场强/中/弱/恐慌，弱市只复盘和观察。
2. 根据行业涨幅、成交额、扩散度和消息验证主线。
3. 从主线中找核心票，绘制平台、下降压力与关键均线。
4. 仅把处于触发区、RR 合格的个股写入交易计划。
5. 收盘复核：是否站稳交点、是否跌回平台、板块是否仍是主线。
6. 复盘时记录是否严格执行，而不只记录盈亏。

## 适用边界

适合趋势、题材扩散和有明确图形结构的阶段；不适合没有主线的混沌震荡、流动性差标的、纯消息赌博，亦不适合以长期基本面为唯一理由的左侧加仓。
