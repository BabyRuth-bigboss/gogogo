# 双体系协作手册

## 先分账户，再谈结合

| 维度 | 水水交易仓 | 价值投资仓 |
|---|---|---|
| 核心问题 | 当下是否有高赔率的右侧机会？ | 资产长期价值是否高于价格？ |
| 典型周期 | 数日到数月 | 数月到数年 |
| 入场依据 | 主线、核心地位、标准图、量能、RR | 质量、估值、周期、预期差、安全边际 |
| 风险控制 | 明确止损、单笔风险、仓位上限 | 分散、估值纪律、现金缓冲、逻辑失效卖出 |
| 退出依据 | 图形/主线失效、止损、趋势退出 | 高估、价值逻辑失效、周期或仓位变化 |

不要将同一笔仓位同时标为交易仓和价值仓。一个账户中的仓位必须只有一个主导逻辑。

## 共享观察池，分别决策

### 研究漏斗

1. **全市场与宏观**：价值体系判断市场水位和行业周期；交易体系判断市场是否允许主动做多。
2. **行业主线**：两者都关注行业景气、供需、政策与资金，但价值体系问持续利润，交易体系问当下资金扩散。
3. **公司清单**：价值体系形成质量/估值候选；水水体系形成主线核心票候选。
4. **执行分流**：
   - 高质量、估值有安全边际、但无交易图形：进入价值观察/分批计划。
   - 主线核心、图形和 RR 合格、但估值未必便宜：只可进入交易仓。
   - 两套都高分：仍按两个独立计划执行，不因“双重认可”取消止损或抬高仓位。
   - 任一体系触发一票否决：不做。

## 下单前的双清单

### 若是交易仓

- 市场、主线、地位、图形、交易五闸门是否都通过？
- 交点/突破位、止损、目标价是否事先写下？`RR >= 2` 吗？
- 仓位是否由单笔风险反推，且已经把 T+1 与跌停风险纳入？
- 若跌回平台、板块转弱或结构失效，是否无条件退出？

### 若是价值仓

- 能否一句话说清企业如何赚钱和护城河？
- 现金流、资产负债表、资本配置与估值是否支持价格？
- 行业处于什么周期，市场定价隐含什么悲观/乐观假设？
- 若跌 20%/40%，是更便宜还是逻辑已坏？是否仍有现金和能力持有？

## 常见错误

1. **用“价值”给交易亏损找借口**：交易触发止损，不能因跌了就改为长期持有。
2. **用“趋势”掩盖高估**：强势不代表安全；价值仓不得因涨速加仓而跳过估值检查。
3. **重复暴露**：同一产业链的个股、ETF、港股可能高度相关，账户分开不等于风险分散。
4. **把宏观当开关**：宏观决定水位和仓位上限，不代替企业研究或交易触发。
5. **先定仓位再找理由**：必须先有计划，后有交易。

## 每周/每月节奏

| 频率 | 水水交易体系 | 价值投资体系 |
|---|---|---|
| 每日收盘 | 市场强弱、主线、交点站稳/跌回、止损执行 | 仅更新重大公告、业绩与估值异常 |
| 每周 | A/B/C/D 池调整，统计交易是否遵守计划 | 产业与竞争变化、持仓逻辑核对 |
| 每月 | 统计胜率、平均 R、最大亏损与违规次数 | 市场季节、水位、组合暴露、研究与再平衡 |
