# 投资思考系统：水水交易 + 价值投资

这是一套“双引擎、双账户”的研究框架：水水体系解决**什么时候做右侧交易**，价值体系解决**什么资产值得长期持有、什么价格值得承担波动**。两者可以共享研究和观察池，但不能用一套规则替代另一套。

## 文件导航

- [水水交易体系](shuishui_trading_system.md)：主线、核心票、标准图、盈亏比、仓位与止损。
- [价值投资体系](value_investing_system.md)：商业质量、估值、周期、预期差与行为纪律。
- [双体系协作手册](dual_system_playbook.md)：如何建立观察池、下单前如何分流、如何复盘。
- `source_skills/`：两套技能的原始规则和参考材料，便于追溯。

## 一句话原则

```text
交易仓：没有主线、图形、盈亏比和止损，不交易。
价值仓：没有商业质量、合理估值、周期判断和持有能力，不买入。
```

所有内容仅用于研究与决策流程训练，不构成投资建议。涉及当前价格、估值、行情、公告或新闻时，必须重新核验数据。
