# Value Investing System

## 系统定位

价值体系用于中长期资产配置、企业研究和估值决策。它研究的是企业未来可分配现金流与买入价格，而不是短期 K 线预测。

```text
长期回报 = 商业质量 x 买入价格 x 周期位置 x 行为纪律
```

## 决策顺序

```text
个人资产负债 -> 市场季节 -> 行业位置 -> 企业质量 -> 估值 -> 预期差 -> 仓位/执行 -> 复盘与退出
```

### 1. 先看自己

- 保留 3--6 个月生活费；不以权益资金支付近期刚性支出。
- 不依靠杠杆与被迫卖出；仓位须能承受真实回撤。
- 先定义持有期、风险承受力及已有行业暴露。

### 2. 用宏观看“水位”，不猜点位

| 市场季节 | 常见信号 | 主要行动 |
|---|---|---|
| 冬 | 低估值、悲观、盈利走弱 | 研究，分批配置高质量资产/指数 |
| 春 | 政策或流动性改善、资产止跌 | 增加敞口，识别受益者 |
| 夏 | 盈利效应扩散、估值上升 | 持有核心，少折腾 |
| 秋 | 高估值、全民热情、杠杆上升 | 分批止盈、防守 |

关注 PE/PB 分位、ERP、M1-M2、社融、PPI、利率、汇率、成交额、两融、基金发行和情绪，但把它们当作概率背景。

### 3. 企业质量与行业位置

核心问题：如何赚钱、护城河是什么、需求是否可持续、利润是否真实、管理层能否合理配置资本、下行期能否生存。

优先验证：商业模式、竞争优势、市场空间与份额、ROE 的来源、经营现金流/自由现金流、应收和存货、负债、分红回购、资本开支与管理层诚信。

### 4. 估值与预期差

- 先用回本期直觉判断价格，再用 PE、PB、DCF、FCF、PEG、PEV 等匹配资产的工具交叉验证。
- 好公司不等于好投资。15--25 倍 PE 需要清晰增长，25 倍以上容错显著下降，40 倍以上需极高确定性。
- 低估不等于便宜：必须排除商业恶化、高杠杆、现金流失真和“极端增长才能合理”的价值陷阱。
- 预期差必须可验证，例如盈利拐点、供给出清、龙头份额提升或经营杠杆释放。

## 100 分评分卡与一票否决

| 维度 | 分值 |
|---|---:|
| 能力圈 | 10 |
| 行业位置 | 15 |
| 公司质量 | 20 |
| 财务质量 | 15 |
| 增长逻辑 | 10 |
| 估值安全边际 | 20 |
| 市场季节 | 5 |
| 行为匹配度 | 5 |

85+ 是核心候选，75--84 可配置/重点跟踪，65--74 等更好价格或更清晰逻辑，65 以下不买。一票否决：看不懂业务、治理诚信疑点、现金流差而故事重、高杠杆叠加下行周期、估值依赖极端增长、买入理由只是“在涨”。

## 仓位与退出

- 指数定投：适用于低估区域的宽基或耐久行业指数，以估值与再平衡止盈，不套用短线止损。
- 个股左侧：只在研究充分且安全边际足够时分批；下跌时先复核价值而非机械补仓。
- 右侧趋势：适合券商、周期或主题，必须小仓试错、确认后加仓、明确止损。
- 卖出：估值过高、逻辑失效、周期转弱、更优机会或仓位失衡；区分“价格波动”与“价值变化”。

## 月度复盘

每月记录市场季节、估值水位、流动性与盈利趋势、组合贡献/拖累、错误与情绪化交易，并对每个持仓重问：原始逻辑是否仍成立？
